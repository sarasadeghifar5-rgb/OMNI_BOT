#### **بخش A: محاسبه ∫ x² ln(x) dx**

این انتگرال نیاز به روش **انتهای ضریب (Integration by Parts)** دارد.
فرمول:
```text
∫ u dv = uv - ∫ v du
```
انتخاب $u$ و $dv$:
```text
u = ln(x)       =>  du = (1/x) dx
dv = x² dx      =>  v = ∫ x² dx = (x³/3)
```
اعمال فرمول:
```text
I_A = ln(x) * (x³/3) - ∫ (x³/3) * (1/x) dx
I_A = (x³/3) ln(x) - (1/3) ∫ x² dx
I_A = (x³/3) ln(x) - (1/3) * (x³/3) + C
I_A = (x³/3) ln(x) - (x³/9) + C
```

**پاسخ بخش A:**
```text
∫ x² ln(x) dx = (x³/3) ln(x) - (x³/9) + C
```

#### **بخش B: محاسبه ∫ x / √(x + 1) dx**

برای این انتگرال، روش **تعویض متغیر (Substitution)** بسیار مؤثر است.

۱. قرار می‌دهیم:
```text
u = x + 1
=> du = dx
=> x = u - 1
```

۲. جایگذاری در انتگرال:
```text
I_B = ∫ (u - 1) / √u du
I_B = ∫ (u - 1) * u^(-1/2) du
I_B = ∫ (u^(1/2) - u^(-1/2)) du
```

۳. انتگرال‌گیری هر جمله:
```text
∫ u^(1/2) du = (u^(3/2) / (3/2)) = (2/3) u^(3/2)
∫ u^(-1/2) du = (u^(1/2) / (1/2)) = 2 u^(1/2)
```

۴. جمع‌بندی و بازگشت به متغیر $x$:
```text
I_B = (2/3) u^(3/2) - 2 u^(1/2) + C
I_B = (2/3) (x + 1)^(3/2) - 2 (x + 1)^(1/2) + C
```

*ساده‌سازی نهایی (اختیاری اما تمیزتر):*
فکتور `(x + 1)^(1/2)` یا `√(x + 1)` را برمی‌آوریم:
```text
I_B = √(x + 1) [ (2/3)(x + 1) - 2 ] + C
I_B = √(x + 1) [ (2x/3 + 2/3 - 6/3) ] + C
I_B = √(x + 1) [ (2x/3 - 4/3) ] + C
I_B = (2/3) √(x + 1) (x - 2) + C
```

**پاسخ بخش B:**
```text
∫ x / √(x + 1) dx = (2/3) √(x + 1) (x - 2) + C
```

#### **بخش C: محاسبه ∫ (x³√x - 3√(9 - x²)) dx**

این عبارت شامل دو ترم است. باید جداگانه انتگرال بگیریم و جمع بزنیم.

**ترم اول:** `∫ x³√x dx`
```text
x³√x = x³ * x^(1/2) = x^(3.5) = x^(7/2)
∫ x^(7/2) dx = (x^(9/2) / (9/2)) + C1
             = (2/9) x^(9/2) + C1
```
*نکته: $x^(9/2)$ می‌تواند به صورت $x^4 \sqrt{x}$ نیز نوشته شود.*

**ترم دوم:** `∫ -3√(9 - x²) dx`
این انتگرال نیاز به **تعویض مثلثاتی** دارد.
فرم عمومی `∫ √(a² - x²) dx` با قرار دادن $x = a \sin(\theta)$ حل می‌شود.

۱. قرار می‌دهیم:
```text
x = 3 sin(θ)
dx = 3 cos(θ) dθ
√(9 - x²) = √(9 - 9sin²θ) = √(9cos²θ) = 3 cos(θ)  [فرض θ در محدوده مناسب]
```

۲. جایگذاری:
```text
I_C2 = ∫ -3 * (3 cos(θ)) * (3 cos(θ) dθ)
I_C2 = -27 ∫ cos²(θ) dθ
```

۳. استفاده از فرمول نیمه‌زاویه `cos²θ = (1 + cos(2θ)) / 2`:
```text
I_C2 = -27 ∫ (1 + cos(2θ)) / 2 dθ
I_C2 = -(27/2) [ ∫ 1 dθ + ∫ cos(2θ) dθ ]
I_C2 = -(27/2) [ θ + (1/2) sin(2θ) ] + C2
```

۴. تبدیل `sin(2θ)` به شکل سینوس و کسینوس ساده برای بازگشت به $x$:
```text
sin(2θ) = 2 sin(θ) cos(θ)
I_C2 = -(27/2) [ θ + (1/2)(2 sin(θ) cos(θ)) ] + C2
I_C2 = -(27/2) [ θ + sin(θ) cos(θ) ] + C2
```

۵. بازگشت به متغیر $x$:
```text
sin(θ) = x/3
θ = arcsin(x/3)
cos(θ) = √(1 - (x/3)²) = √(9 - x²)/3

sin(θ)cos(θ) = (x/3) * (√(9 - x²)/3) = x√(9 - x²)/9
```

۶. جایگذاری در نتیجه ترم دوم:
```text
I_C2 = -(27/2) [ arcsin(x/3) + (x√(9 - x²))/9 ] + C2
I_C2 = -(27/2) arcsin(x/3) - (27/2)*(x√(9 - x²))/9 + C2
I_C2 = -(27/2) arcsin(x/3) - (3/2) x √(9 - x²) + C2
```

**جمع‌بندی نهایی بخش C:**
```text
∫ (x³√x - 3√(9 - x²)) dx
= (2/9) x^(9/2) - (27/2) arcsin(x/3) - (3/2) x √(9 - x²) + C
```
