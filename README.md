# 🤖 ربات هوش مصنوعی تلگرام (ChatGptSollBot)

ربات هوش مصنوعی پیشرفته چندمنظوره برای تلگرام با اتصال همزمان به سرویس‌ها و مدل‌های پیشرفته:
- **CleanAPIs**: پرچمداران Claude 5, Claude 5.5 Opus, GPT-5.6 Sol, DeepSeek V4 Pro, Gemini 3.7 Flash, Qwen 3.8, Kimi K3
- **مدل هوشمند پرو**: تولید تصویر 4K، ادیت تکی و گروهی عکس‌ها (Multi-Image Composition)، متحرک‌سازی عکس به ویدیو، تولید ویدیو و استدلال عمیق با پنجره ۲۰۰ هزار توکن
- **Google Gemini (AI Studio)**: پردازش چندرسانه‌ای، بینایی تصویر و چت

---

## 🚀 ویژگی‌های افزوده شده

1. **👥 ادیت و ترکیب عکس‌های گروهی (Multi-Image Composition):**
   - ارسال چند عکس به صورت آلبوم گروهی تلگرام یا تک‌تک.
   - شمارشگر هوشمند تعداد عکس‌ها و دکمه اختصاصی `[ ✅ تایید عکس‌ها ({N} عکس) و نوشتن پرامپت ]`.
   - دریافت پرامپت برای ترکیب کاراکترها، پس‌زمینه‌ها یا استایل‌های عکس‌های مختلف و ساخت یک خروجی واحد.

2. **🔋 نوار لودینگ شارژی با درصد پیشرفت زنده:**
   - نمایش درصد پردازش باتری (`🪫` تا `✅ ۱۰۰٪`) حین تمام عملیات‌های عکس، ادیت و ویدیو.

3. **📝 بدون محدودیت طول پرامپت:**
   - حذف کامل محدودیت ۱۰۲۴ کاراکتری کپشن تلگرام با جریان دو مرحله‌ای (ارسال عکس -> ارسال پیام متنی با طول نامحدود یا فایل متنی).

4. **🏷 برندینگ یکپارچه «مدل هوشمند پرو»:**
   - کلیه بخش‌های چندرسانه‌ای و استدلال عمیق با نام «مدل هوشمند پرو» نام‌گذاری شده‌اند.

کافیست روی فایل **`run_bot.bat`** دو بار کلیک کنید!
