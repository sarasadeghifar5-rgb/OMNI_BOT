# 🤖 OmniLLM Hub - پلتفرم چت هوش مصنوعی جامع و همه‌کاره

یک سرویس چت مدرن، سریع و فول‌امکانات با قابلیت اتصال به انواع مدل‌های پیشرفته هوش مصنوعی در دنیا، جستجوی زنده در وب (Grounding)، تحلیل و بینایی تصاویر (Vision)، نمایش گام‌های استدلال عمیق (Thinking Process)، و اجرای زنده کدهای تولیدشده (Interactive Artifacts).

---

## ✨ قابلیت‌ها و ویژگی‌های کلیدی

### ۱. پشتیبانی از تمامی مدل‌های هوش مصنوعی برتر جهان
- **DeepSeek:**
  - `DeepSeek R1 (Reasoner)`: استدلال منطقی عمیق با رندر زنده فرآیند فکر (`<thinking>`).
  - `DeepSeek V3`: فوق‌العاده باهوش، سریع و دقیق برای کدنویسی و پاسخ‌دهی.
- **OpenAI:**
  - `GPT-4o` و `GPT-4o Mini`: بینایی ماشین پیشرفته و پردازش همه‌جانبه.
  - `o1`: مدل تفکری پیشرفته برای مسائل پیچیده.
- **xAI (Grok):**
  - `Grok-2 Vision` و `Grok-2`: هوش مصنوعی ایلان ماسک با درک متن و تصویر.
- **Zhipu AI (GLM):**
  - `GLM-4V Plus`: تخصصی برای تحلیل تصاویر، اسناد و متون.
  - `GLM-4 Flash`: فوق‌العاده ارزان و سریع.
- **Google Gemini:**
  - `Gemini 2.0 Flash` و `Gemini 1.5 Pro`: پنجره زمینه میلیونی و قدرت بینایی بالا.
- **Anthropic Claude:**
  - `Claude 3.5 Sonnet`: بهترین مدل برای کدنویسی، نگارش ادبی و ساخت آرتیفکت‌ها.
- **OpenRouter & Local Ollama:**
  - دسترسی به بیش از ۱۰۰ مدل دیگر یا اجرای مدل‌ها به شکل کاملاً آفلاین و لوکال.

---

### ۲. جستجوی زنده در وب (Live Web Search & Grounding)
- امکان روشن/خاموش کردن وب‌سرچ برای هر پیام با یک کلیک.
- جستجوی اطلاعات لحظه‌ای و اخبار به‌روز با DuckDuckGo (رایگان و بدون نیاز به کلید) یا Tavily AI.
- نمایش کارت منابع (Citations) با عنوان، لینک و خلاصه متن مستندات.

---

### ۳. تحلیل تصاویر و فایل‌های چندرسانه‌ای (Vision & OCR)
- امکان آپلود مستقیم تصویر، کشیدن و رها کردن (Drag & Drop) یا چسباندن از کلیپ‌بورد (`Ctrl + V`).
- بهینه‌سازی و فشرده‌سازی خودکار تصاویر جهت جلوگیری از مصرف بی‌رویه توکن و ترافیک.
- تحلیل نمودارها، حل مسائل دست‌نویس و استخراج متن اسناد.

---

### ۴. جعبه‌شنی و پیش‌نمایش آرتیفکت‌ها (Live Sandbox Artifacts)
- رندر و اجرای زنده کدهای تولیدشده در HTML، CSS، JavaScript، SVG و دیاگرام‌ها.
- امکان تست زنده برنامه‌ها درون پنجره پیش‌نمایش در کنار چت.

---

### ۵. مدیریت کلیدهای API (BYOK) و حریم خصوصی
- امکان ذخیره کلیدهای API شخصی (OpenAI, DeepSeek, Grok, GLM, Claude, Gemini) در بخش تنظیمات مرورگر.
- یا تنظیم مرکزی کلیدها در فایل `.env` سرور.

---

## 🚀 راهنمای سریع اجرا

### ۱. اجرای مستقیم با پایتون
تنها با اجرای یک دستور، سرور و رابط کاربری راه‌اندازی می‌شود:

```bash
python run.py
```

پس از اجرا، مرورگر خود را باز کرده و به نشانی زیر بروید:
👉 **`http://127.0.0.1:8000`**

---

### ۲. تنظیم کلیدهای API (اختیاری)
می‌توانید فایل `.env` را در ریشه پروژه باز کنید و کلیدهای مورد نظر را قرار دهید:

```env
DEEPSEEK_API_KEY=sk-...
OPENAI_API_KEY=sk-...
GROK_API_KEY=xai-...
GLM_API_KEY=...
GEMINI_API_KEY=AIzaSy...
ANTHROPIC_API_KEY=sk-ant-...
TAVILY_API_KEY=tvly-...
```

*همچنین بدون تغییر این فایل می‌توانید روی آیکون چرخ‌دنده (تنظیمات) در منوی برنامه کلیک کرده و کلیدهای خود را به راحتی ذخیره کنید.*

## 🤖 ربات تلگرام مقیاس‌پذیر و پرسرعت (High Concurrency Telegram Bot)

ربات تلگرام پروژه با معماری کاملاً غیرهمگام (Async / `aiogram 3`)، دیتابیس با کش موازی (`aiosqlite` + WAL Mode)، سیستم جلوگیری از اسپم (Throttling) و مدیریت صف و همزمانی طراحی شده است تا **هزاران کاربر همزمان** بتوانند بدون افت سرعت از تمامی قابلیت‌های هوش مصنوعی استفاده کنند.

### ✨ امکانات ربات تلگرام:
1. **پشتیبانی از تمام مدل‌ها:** دیپ‌سیک (R1 با نمایش زنجیره تفکر و V3)، گوگل جمینای، OpenAI (GPT-4o و o1)، کلود ۳.۵، گروک ۲ و مدل‌های رایگان OpenRouter.
2. **استودیو عکس نانو بنانا (Google Nano Banana):** تولید عکس با دستور `/banana` یا دکمه‌های منو.
3. **بینایی ماشین (Vision):** ارسال مستقیم هرگونه عکس و سند جهت تحلیل، استخراج متن و پاسخ به سوالات.
4. **وب‌سرچ زنده:** فعال یا غیرفعال‌سازی جستجوی لحظه‌ای وب با دکمه اختصاصی.
5. **تبدیل متن به صوت (TTS):** خوانش صوتی پیام‌ها با صدای طبیعی هوش مصنوعی گوگل با دستور `/voice`.
6. **مدیریت نشست و حافظه مستقل برای هر کاربر:** هر کاربر تاریخچه گفتگوی مجزا و پنجره زمینه هوشمند دارد.

### 🚀 نحوه اجرای ربات تلگرام:
1. فایل `.env` را باز کرده و توکن ربات خود را قرار دهید:
   ```env
   TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRstuVWXyz
   TELEGRAM_ADMIN_IDS=123456789
   ```
2. دستور زیر را در ترمینال اجرا کنید:
   ```bash
   python run_bot.py
   ```

## 📁 ساختار پروژه

```

├── app/
│   ├── bot/                  # هسته کامل ربات تلگرام مقیاس‌پذیر (aiogram 3)

│   │   ├── database.py       # دیتابیس SQLite ناهمگام با حالت WAL
│   │   ├── middlewares.py    # کنترل همزمانی و محدودسازی نرخ درخواست (Anti-Flood)
│   │   ├── keyboards.py      # منوهای شیشه‌ای و کیبوردهای تعاملی
│   │   └── utils.py          # تکه‌بندی امن پیام‌ها و فرمت‌بندی Markdown
│   ├── config.py             # کاتالوگ مدل‌ها و تنظیمات ارائه‌دهندگان
│   ├── main.py               # برنامه FastAPI و اندپوینت‌های SSE
│   ├── providers/            # درگاه‌های ارتباطی با OpenAI, DeepSeek, Grok, GLM, Claude, Gemini
│   ├── services/
│   │   ├── gateway.py        # درگاه مرکزی هماهنگ‌کننده مدل‌ها
│   │   ├── web_search.py     # موتور جستجوی وب زنده
│   │   ├── vision.py         # ماژول پردازش و فشرده‌سازی تصاویر
│   │   ├── puter_image.py    # استودیو عکس نانو بنانا
│   │   ├── gemini_tts.py     # سنتز صوتی هوش مصنوعی
│   │   └── storage.py        # مدیریت نشست‌ها و ذخیره تاریخچه
│   └── static/               # رابط کاربری تحت وب
├── .env                      # تنظیمات و کلیدها
├── requirements.txt          # لیست پکیج‌های پایتون
├── run.py                    # اجرای وب‌سرور
├── run_bot.py                # اجرای مستقیم ربات تلگرام
└── README.md
```
